# Known Issues & Open Questions — Sci Infinity (FODOL)

Honest gap register. Every entry carries evidence status: **VERIFIED** (checked in code) or
**INFERRED** (strong evidence, not directly executed). Nothing here is "fixed" until the item is
removed and a PR/commit cited.

> This complements [`docs/ai/GOTCHAS.md`](ai/GOTCHAS.md) (pitfalls to *avoid while working*).
> KNOWN_ISSUES is the list of *things already known to be off*, tracked for resolution.

## 1. Design-token duality — `@theme` palette ≠ release-checked `:root` tokens

**VERIFIED.** `src/index.css` declares two different sets of brand hexes:

- Tailwind `@theme` utilities (what components *actually use*: `brand-purple`, `brand-indigo`, …):
  `#5D3B8E`, `#4553A5`, `#2175C9`, … — e.g. `brand-purple: #5D3B8E`.
- `:root` custom properties + `.brand-verified-tokens` marker class:
  `#111020 #56368d #434a9a #3b56a6 #2774bb #1196d3` — the exact set `scripts/verify-release.js`
  hard-checks in both `src/index.css` and the compiled CSS.

They diverge slightly (e.g. `#5D3B8E` vs `#56368d`). The release gate passes because it checks that
the legacy `:root` set *exists*, not that components consume them. If someone "cleans up" one set,
either rendered colors shift or the release gate breaks. **Fix:** reconcile into a single palette and
update the `requiredTokens` list in `verify-release.js` in the same change (see `CONTRIBUTING.md`).

## 2. `pdfjs-dist` declared but unused

**VERIFIED.** `package.json` declares `pdfjs-dist`, but nothing imports it from `node_modules`.
Instead `src/components/common/PdfThumbnail.tsx` and `src/views/AnnualForumView.tsx` load PDF.js
**from a CDN at runtime** with `/* @vite-ignore */` (kept out of the bundle on purpose).
The dependency is dead weight in `package.json`. **Risk:** none functional; a future `npm i` could
make the import path "look" valid and get bundled accidentally.

## 3. `vite-plugin-pwa` installed but not used

**VERIFIED (devDep present, no import).** No `vite-plugin-pwa` reference in `vite.config.ts`. The
PWA is **hand-maintained**: `public/sw.js`, `public/manifest.json`, `public/offline.html`, registered
manually in `src/main.tsx`. The release gate checks their presence (checks 3–5). **Risk:** none
today; if the project later adopts the plugin, delete the hand-maintained files to avoid double
registration.

## 4. Dead environment config

**VERIFIED.** These variables exist in `.env.example` / `.env.fodol.example` but are referenced
**nowhere** in `src/` or `scripts/` (grep over the whole tree returns zero hits):

- `VITE_DB_MODE` (mock/live)
- `VITE_ENABLE_LIVE_FORMS`
- `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`

Only `VITE_FODOL_API_BASE` and the built-in `BASE_URL` are actually read. **Risk:** misleading —
an agent or dev may believe toggling these changes behavior. Enabling live forms also requires
privacy/legal sign-off (see `AGENTS.md` Never list). Either wire them up or remove them from the
examples, with maintainer sign-off.

## 6. No license file

**VERIFIED.** No `LICENSE` / `LICENSE.md` at the repo root. The `README.md` now states this
explicitly. **Action:** decide licensing with the maintainer (non-profit initiative content).

## 7. PDF.js CDN has no SRI pinning

**VERIFIED.** `PdfThumbnail.tsx` / `AnnualForumView.tsx` load PDF.js from a CDN with
`/* @vite-ignore */`. No Subresource-Integrity hash, no version pin beyond the URL. **Risk:** the
CDN content is third-party-trusted at runtime. **Fix:** pin a known version and add an `SRI`
`integrity` attribute, or vendor the lib locally.

## 8. No unit / integration test framework

**By design — see [ADR 0003](adr/0003-release-gate-not-unit-tests.md).** Not a defect, but listed
here so a future agent does not mistake it for an oversight. The release gate
(`scripts/verify-release.js`) is the automated proof; runtime behavior is checked manually
(dual-locale checklist in `AGENTS.md`).

## 9. Git history is not a changelog

**VERIFIED.** `git log --oneline` shows messages `"9"`, `"8"`, `"7"`, … — numbered placeholders,
not conventional commits. There is no in-repo CHANGELOG. For release notes, rely on the GitHub
releases UI or the ADRs, not the commit log.

## 10. `public/magazine/**` is generated but committed

**VERIFIED.** `.gitignore` does not exclude the magazine tree; it is committed static output
regenerated by the server-side ingest pipeline (see [ADR 0005](adr/0005-static-magazine-pre-render.md)).
AGENTS.md forbids hand-editing it. The tension (generated → committed) is deliberate: the site must
deploy with no server. **Watch for:** accidental commits of intermediate render artifacts.
